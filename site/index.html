Install in four steps

The APK is installed directly, outside the Play Store, so Android asks once for permission.

1

Download

Tap the button above on the phone, or scan the QR code. The file is qualihive-release.apk.

2

Open the file

Pull down the notification or open Files → Downloads and tap the APK.

3

Allow the install

If asked, allow Install unknown apps for your browser or Files app, then go back and tap Install.

4

Create your account

Open Qualihive and set up the local account that owns the batch records. Nothing leaves the phone.

ⓘ
Requirements: Android 7.0 or newer, 64-bit (any phone from about 2017 on), with Bluetooth Low Energy. Updating later is the same: download the new APK and install over the old one — your data stays.

What it does

Built around the four questions a beekeeper asks at the machine.

  • Live digital twin of the machine: stage, pumps, filters, jar level
  • Every parameter graded: pH, moisture, conductivity, colour, temperature, turbidity
  • Three-level result — per parameter, overall, and what to do with the batch
  • Automatic batches with a frozen verdict and traceable QH-YYYY-NNNN codes
  • History, statistics and trends across batches
  • Editable reference values with provisional ranges clearly marked
  • Notifications for out-of-range readings, sensor faults and disconnections
  • PDF quality reports and CSV exports, shared from the phone
  • Offline by design — accounts and records stay on the device
  • Built-in simulator for demos when the machine is not around

Connecting to the machine

The app speaks to the ESP32 over the Nordic UART service.

1

Turn on Bluetooth

Open More → Machine connection, keep Bluetooth device selected and tap Scan for devices. Allow the Nearby devices prompt.

2

Pick the machine

Tap it in the Found list. The pill in the corner turns green once the link is up.

3

Run a batch

A batch opens on its own when the machine starts a cycle. If the firmware sends no stage, tap Start on Home.
